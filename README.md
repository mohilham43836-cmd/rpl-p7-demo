# Sistem Tanggap Darurat RT

Sistem Tanggap Darurat RT adalah aplikasi berbasis IoT dan Mobile App yang dirancang untuk membantu warga melaporkan serta menangani situasi darurat secara cepat dan terintegrasi di lingkungan RT/RW.

---

## 📁 Struktur Direktori Proyek

Berikut adalah struktur folder dan berkas utama yang ada di dalam repository proyek ini:

```text
rpl-p7-demo/
│
├── requirements/      # Dokumen analisis kebutuhan perangkat lunak (SRS, user stories, dsb.)
│   └── srs.md         # Draft Software Requirements Specification
│
├── uml/               # Diagram pemodelan sistem (Use Case, Activity Diagram, Class Diagram)
│
├── src/               # Kode sumber (source code) utama aplikasi
│   └── main.py        # Skrip program utama
│
├── test/              # Berkas pengujian perangkat lunak (unit testing, integrasi)
│
├── .gitignore         # Daftar berkas/folder yang diabaikan oleh Git
└── README.md          # Dokumentasi dan penjelasan struktur proyek
